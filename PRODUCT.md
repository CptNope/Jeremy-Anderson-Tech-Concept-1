## Product Principles

1. Sell outcomes, prove with engineering — show the system when it builds trust, never as decoration.
2. Radical honesty: published prices, founder-led, no invented proof.
3. Security and accessibility are defaults, visible in how the site itself is built.
4. One accountable lead across web, AI, security and infrastructure.
5. Performance is part of the brand: the site must be fast on a mid-range phone.

## Accessibility & Inclusion

WCAG 2.2 AA minimum (founder holds W3C/WAI accessibility certification — the site must visibly live up to it). Full keyboard support, reduced-motion alternatives for every animation, readable contrast on dark surfaces, no information carried by color alone.
