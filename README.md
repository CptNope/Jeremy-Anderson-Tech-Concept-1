# Jeremy Anderson Tech · Concept 1

Brand identity and website concept for **Jeremy Anderson Tech**, Direction 01: Future Systems, built in the *Calibrated Signal* visual world.

- **Website concept:** `/` (15 static pages: home, services and pricing, four channel pages, work and three case studies, about, approach, insights, contact, site map)
- **Brand book:** `/brand-book/` (strategy, logo system, color, typography, motion, components, applications, design tokens)
- **Logo files:** `/brand-book/assets/*.svg`
- **Product and design records:** `PRODUCT.md`, `DESIGN.md`

Static HTML, CSS and vanilla JS with no build step for hosting. Phase 2 is a custom WordPress block theme using the tokens in the brand book (section 17).

The concept is excluded from search (`noindex` and `robots.txt`). Canonical URLs point to the planned production paths on jeremyanderson.tech.

Fonts: Archivo and Martian Mono (SIL Open Font License 1.1) via Google Fonts.
