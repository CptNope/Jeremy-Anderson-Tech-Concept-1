Logo system

A monogram drawn as one beam trace, a wordmark set in outlined Archivo Expanded, and a ruler that measures.

Primary horizontal lockup on Graticule. The JAT trace reads as a step response: the line enters at rest, the J and A form the transient, and the T settles at the trigger level.

Clear space and minimum size

Keep at least X clear on every side, where X is one grid division: the height of the J tail, or about 0.29 × the mark's height. Never place other marks, text or edges inside that zone.

Production rules

  • The wordmark is outlined from Archivo Expanded (width 125, weight 620, tracking +40). TECH uses weight 380, tracking +320. No live text inside logo files.
  • The monogram stays a stroke in source files so weight can be audited. Expand strokes only for embroidery, vinyl cutting and laser etching.
  • Recolor with currentColor or the --mk, --lk-name, --lk-tech, --lk-rule custom properties. Never edit path data.
  • Favicons: export jat-icon.svg at 16, 32, 180, 192 and 512 px; ship the SVG as rel="icon" for modern browsers.
  • Print: convert to CMYK at the printer using the values in section 10. Spot alternative: Pantone 319 C for Channel Cyan.

Pairing rules

  • Headings run expanded (112–125); body text stays at width 100 for reading comfort.
  • Emphasis comes from weight and width, never italics, color gradients or underlines.
  • Mono appears only when the content is data. A headline in mono is a costume.
  • Running text measure: 60–72 characters. Headings wrap with text-wrap: balance.
