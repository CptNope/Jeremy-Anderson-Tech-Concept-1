# Fonts

The wordmark generator (`design/identity/wordmark.py`) outlines text from the Archivo variable font. Font files are not committed.

Download the variable fonts from the Google Fonts repository and save them here:

| File to save here | Source |
|---|---|
| `Archivo-Variable.ttf` | https://github.com/google/fonts/blob/main/ofl/archivo/Archivo%5Bwdth%2Cwght%5D.ttf |
| `MartianMono-Variable.ttf` (optional, for local previews) | https://github.com/google/fonts/blob/main/ofl/martianmono/MartianMono%5Bwdth%2Cwght%5D.ttf |

Both are licensed under the SIL Open Font License 1.1. The published pages load them from Google Fonts; the WordPress theme should self-host WOFF2 subsets with the OFL text included.
