The Calibrated Signal identity for Jeremy Anderson Tech: a block theme that replaces Developer Portfolio without losing content.

== Description ==

JAT Signal keeps every block, post type, taxonomy, meta field and page template from the Developer Portfolio theme, so switching themes restyles the existing site. It adds the concept page layouts, a contact form, and a screen under Appearance › JAT Signal that applies them with one click, with one-click restore.

On a brand-new WordPress install, activation sets up the complete site: services and prices, Home, Services, Projects, About, Blog, the concept pages and the legal pages. On a site with existing content, activation only adds the concept pages as drafts.

See README.md for the full guide.

== Installation ==

1. Back up the site.
2. Appearance › Themes › Add New › Upload Theme, choose jat-signal.zip, then Activate.
3. Existing site: open Appearance › JAT Signal to apply the concept layouts, review and publish the draft pages, and set the contact email.
4. New site: everything is set up on activation. Add projects, posts and a portrait, and set the site title under Settings › General.
